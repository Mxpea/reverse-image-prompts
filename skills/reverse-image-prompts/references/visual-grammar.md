# 视觉语法与提示词编译

用于反推和编译阶段。只分析与目标有关的维度，不要求每次完整填写全部条目。

## 从观察到可执行描述

| 维度 | 要找的证据 | 优先写成什么 | 常见误差 |
| --- | --- | --- | --- |
| 外轮廓 | 最远仍可辨认的大形、宽高关系 | 扁椭圆／长梨形／方块／楔形，以及各自的连接关系 | 只说“可爱”，结果变成另一类标准吉祥物 |
| 连接结构 | 头身、肢体、零件的连接与遮挡 | 连为平滑大形、嵌入、悬挑、贴附，哪些不能分离 | 明明要连续形体，却生成脖子、肩膀或额外接缝 |
| 动势 | 重心、支撑面、弯曲方向、接地 | 下垂、塌坐、悬浮、倚靠、紧绷等可见姿势 | “短爪”变圆拳头，未写清方向与连接 |
| 线条 | 粗细层级、线色、稳定性、纹理 | 普通轮廓与强调笔画的粗细关系，是否有颗粒 | “手绘／铅笔”触发粗笔刷、纸纹或水彩 |
| 色彩 | 主色块位置、明暗与饱和度关系 | 保留色相类别和分色位置，再控制浓淡 | 全部粉彩化导致黑发变白、身份丢失 |
| 阴影 | 层数、边缘、分布与光源 | 每大形一块硬边浅影／渐变体积／无阴影 | 只有“平涂”一词，仍出现多层光影和高光 |
| 材质 | 靠纹理、轮廓还是反光表达 | 哪些线索必须有，哪些刻意不画 | 本来只是平滑色块，却出现绒毛或塑料光泽 |
| 密度 | 发束、鳞片、折线等重复结构 | 保留轮廓，删内部重复；指定必要的简化层级 | 在要求极简时仍强调全部饰物精度 |
| 构图 | 视角、主体占比、留白、裁切、背景 | 全身／半身、相对位置、必要的空白与接地 | 把截图版式、人数和字幕当作目标风格 |

### 正向描述先于排除词

先说明想要的结构，再排除最可能的替代结构。例如：

- 不充分：“不是猫，不是人，不要毛绒。”
- 更可执行：“脸到腹部连成平滑的大色块；两条水滴形前肢向下垂；底部后足与躯干连成豆形凸起。不要毛领、圆拳头或独立猫脚。”

数字只用来消除实际歧义。相对比例通常比任意精确数值更可迁移；不要因为单张观察就给所有题材固定头身比、线宽或阴影数量。

## 身份迁移不是细节复制

先判断哪些特征让人认出主体，再决定它们在目标画法中的表达方式：

- 人物：发型大轮廓、发色分区、眼镜／头饰、独特标记；眼睛被目标闭眼造型取代时，不强求虹膜颜色仍可见。
- 生物与非人角色：耳角数量、尾尖、翅膀、背甲等形态，保留辨识轮廓而不照搬复杂材质。
- 产品与图标：主体剪影、关键开孔、按钮关系、品牌识别色；“简化”不能删除功能上或视觉上定义对象的部件。
- 场景：空间组织、建筑剪影、尺度关系、时间／天气线索；不把人物类的头身分析强加给场景。

用条件规则处理例外，不给所有角色都添加某种配件。服装、胡须、帽子或机械结构若是身份核心就转译，不因某个过往案例而一概删除。

## 可组合的提示词骨架

下面是编写提示词的骨架，不是要求用户逐格填写的表单。交付前将目标画风的占位内容写实；只在确实需要变更的主体设定上保留变量。

```text
任务：将输入主体按以下造型与绘制规则重新设计。输入仅提供身份，不沿用其中的画法、姿态或背景，除非下文明确要求。

固定造型：〔写清主要轮廓、比例、连接、关键结构与动势〕。
身份迁移：自动保留最可辨认的少量特征，转译为〔目标风格允许的表达方式〕。〔写入当前类别必要的条件分支〕。
绘制规则：〔线条粗细与颜色关系〕；〔主色与分色处理〕；〔阴影与边缘〕；〔纹理和细节密度〕。
构图：〔主体数量、裁切、视角、留白、背景〕。
冲突优先级：〔本任务最重要的结构／风格规则〕优先于次要装饰，不牺牲核心身份。
避免：〔仅写本任务最可能出现的几个错误替代方案〕。
```

单图重建模式把“输入身份”改为明确的主体内容。不要在文生图提示词里留下没有提供的“输入人物图”。

## 通用性检查

- 换发色、性别、长短发、配件以后，固定画法是否仍成立？这只是静态检查，不等于已经生图通测。
- 规则是否偷用了样例的角、白发、白底或姿势？它们究竟是目标风格不变量，还是偶然内容？
- 是否混用“极简”与“全部细节完美复刻”、“粗糙手绘”与“无纹理细线”等互相拉扯的要求？
- 某个身份变量与固定结构冲突时，是否有明确的保留与简化方式？
- 移除目标图片之后，提示词本身能否描述目标，而不依赖“同款”“像右下角”或隐藏风格标签？

## 发现偏差时的修正方向

| 实际结果 | 先检查／修改什么 |
| --- | --- |
| 正确配色但属于另一类造型 | 修大轮廓、连接、肢体形状；不要先补饰物 |
| 仍像源图画法 | 明确输入只供身份；把目标线条、阴影、密度写实，不偷偷增加风格图 |
| 过度精修或材质化 | 查找“精美、毛绒、铅笔、水彩”等可能引入材质的正向词，保留真正需要的绘制机制 |
| 身份不像 | 补最关键的具体锚点与分色位置，不直接要求所有细节恢复 |
| 身体正确但局部错误 | 保持骨架，只改该局部；不要把一次小修变成全套重写 |
| 负面词很多仍不对 | 用更明确的正向结构替换抽象排除，不继续堆同义词 |
