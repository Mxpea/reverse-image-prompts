# 实测、预算与证据

仅在用户要求实际生图或继续已授权循环时读取。这个文件不授予任何新的网络、付费或安装权限。

## 执行前

1. 沿用用户明确选定的服务与模型。第三方站点的模型别名不证明底层模型身份；不擅自换模型，也不为“查清别名”把凭据发给其他服务。
2. 使用已有图像工具／执行 skill。没有支持的能力时说明阻断并交付提示词，不临时修改受保护的工具脚本或绕过执行限制。
3. 先写出或保存本轮提示词。只读能力查询与付费生成分开计数；不通过实际生图反复探测未经确认的端点。
4. 先确定本轮保守的小批量与停止条件，尊重用户明确的费用、张数或调用上限。用户说“约十次”不是无限重试授权，也不必为了凑整耗尽额度。
5. 凭据仅用于所选服务，不写入 skill、交付物、持久脚本或日志，不复述完整密钥；优先运行时秘密变量。清理局部引用不是服务端撤销或聊天历史删除，不承诺不可验证的彻底销毁。

## 输入隔离

| 声明的工作流 | 可以传给生成模型的内容 | 不能偷加的内容 |
| --- | --- | --- |
| 纯文生图 | 已写实的内容＋风格提示词 | 原始参考图片、隐式参考附件 |
| 纯提示词转换 | 当前待转换主体图＋独立风格文字 | 画风图、其裁切、拼贴、此前携带目标风格的输出图 |
| 双参考转换 | 用户允许的身份图和风格图 | 未声明的其他参考；错配图片编号 |

反推时看过的参考图可以留作结果评估，但不得因为“只是帮助一下”上传到纯提示词测试请求。隐式附件或工具继承图片也要检查；无法确认隔离时不要声称测试证明了独立文字能力。

## 最小实测记录

不必强制一种文件格式，但要保留：

- 版本／实验意图、实际模型标识、实际提示词。
- 生成调用的输入角色与数量，是否上传风格参考；若需要证据，可记录非敏感文件名或摘要，不把用户图片永久打包进 skill。
- 实际请求次数；是否成功响应、保存、打开检查。
- 看到了哪些结构性偏差、这次要改哪一个主要因素。
- 错误状态、停止原因与仍未验证的能力。

不虚构定量相似度。视觉观察是人工判断，就按人工判断报告；静态情景审查、独立抽样复测、跨角色验证是不同证据等级。

## 自我改进循环

1. 用最小可用样例先得到一张可查看的结果；工具已验证可稳定处理输入输出且预算允许时，才考虑小并发抽样。
2. 先看主体轮廓与绘制机制，再看身份锚点与小装饰。确认结构匹配不代表所有细节已通过。
3. 选择最大偏差，用可观察的因果假设写修正。例如：“前爪像拳头，是因为只写了短爪而没有描述下垂形状”。
4. 保持其他条件尽量不变，只针对该偏差改提示词，再查看新图。重新从原始主体输入生成通常更适合检验模板独立能力；上传前一张图做修图属于另一种工作流，必须标明。
5. 抽样并发只用来观察稳定性；提示词、图片顺序、模型、尺寸同时改变的结果不能归因于单一因素。
6. 目标轮廓、画法和身份达到用户可接受程度即停。仍有细小差异时如实指出，不把“没有必要继续消费”说成完美复刻。

## 先区分生成失败与取图失败

- API 返回图片链接、base64 或其他合法结果形式时，按可用工具支持的协议读取，不假定永远存在某一字段。
- 在格式转换前保留足够的非敏感元信息以便恢复。链接有签名／访问令牌时按敏感信息处理，不写进公开日志。
- 已成功生成但下载或保存失败，优先恢复原响应或重试取图，不立刻重新生成并重复消费。受工具能力限制无法恢复时如实记录。
- HTTP 成功但结果不含可用图片，不能当成成功出图；HTML 错误页也不能当 JSON 图片结果。
- 鉴权或余额错误先停止付费请求。超时可能已被服务端接受或扣费，不能把一次超时当成“免费失败”自动重试。
- 同类网关故障连续出现时停止盲试，报告已提交次数和可恢复结果，保留余额。清除本地计时器不能取消已被远端接收的生成任务。
- 能查询额度就使用站点实际单位，不猜货币或可生成张数；说明查询时间与超时请求后续结算的不确定性。

## 明确标注验证状态

| 事实 | 可报告的结论 |
| --- | --- |
| 仅分析并写好文字 | 未生图验证的反推稿 |
| 一个人物输入、未上传风格图，成功查看输出 | 该样例的纯提示词工作流已实际执行，不代表达到目标或普遍有效 |
| 图片像目标，但同时上传了风格图 | 双参考样例有效，不证明纯提示词有效 |
| 看过 V1 图，写了 V2，但 V2 请求超时 | V2 基于实测问题修订，V2 本身未验证 |
| 若干不同角色在同一固定模板下表现一致 | 对已列出的角色有迁移证据，不能外推到所有角色／模型 |
| 只检查了模板分支与矛盾 | 静态通用性审查，不是跨角色生图测试 |

## 结束时

交付主提示词、真实版本对应的图片与必要的对照。未验证的修订不冒用旧图。报告新增请求数和本轮成功保存数；有累计上限时也报告累计数。清理本轮临时凭据引用和不再需要的任务，但不把它说成用户服务端密钥已撤销。
